# Working on MDLM Process Packages

Before changing this repository, read [CONTRIBUTING.md](CONTRIBUTING.md). It owns
cloud setup, validation, review and release expectations. Use the GitHub issue
and PR for task scope, progress, evidence and handoff so another cloud checkout
can resume the work.

For changes to lifecycle behavior or prompts, read the selected package README,
its relevant prompts and skills, and [PROCESS-LEARNINGS.md](PROCESS-LEARNINGS.md).
Keep requirements quality, independent verification and review intact. Fix an
observed process problem in the instruction that owns it and record the learning.
Keep unrelated changes out of the diff.
