# Explore the next prototype slice

Read exact `experiment`, `trials` and `observations` from guidance, then any linked
stakeholder feedback. Publish a successor in that same EXP lineage. Preserve
the closed brief, runnable source and all prior observations and results as history.

Name the next useful integrated slice, its learning question, provisional approach,
constraints, time allowance and first scope cut. Explain which prior learning
supports this scope. Keep criteria provisional until stakeholder intent justifies
formal requirements. Closure of the earlier slice does not accept the whole product.

Select the complete necessary public ICD set with exact `uses-interface` links,
retaining unchanged interfaces and explicitly adopting any changed ones before
exporting the successor criterion context. Independently author verification for
that exact new EXP before preparing its TRY. Earlier PASS results describe their
original criteria and source; execute the successor's selected verification on
its own committed prototype and record fresh observations through ordinary actions.
