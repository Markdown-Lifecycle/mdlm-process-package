# MDLM Process Packages

Independently released declarative data for the MDLM kernel. The data-only catalog selects the tiny, exploratory and iterative package directories. See RELEASE-NOTES.md for compatibility and existing-product impact, and each directory README for its process.

Run `npm pack` to build the data distribution. Install its exact Git commit or packed tarball alongside the kernel. The original source history remains available through PROVENANCE.json.
